## Test Case 1: Business Report on Market Trends

# Scenario 1 – Business Report on Market Trends

| Stage                   | Prompt Used                                                                                                                 | Pattern Highlighted   | Output Effect                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------- | ------------------------------------------------------- |
| **Basic Prompt**        | “Write a short report on global e-commerce market trends.”                                                                  | *Simple prompt*       | Gave a single paragraph with a few stats, no structure. |
| **Query Decomposition** | “Break the report into sections: Introduction, Current Market Status, Regional Trends, Key Growth Drivers, Future Outlook.” | *Query decomposition* | Output split into clear headings.                       |
| **Decision Making**     | “Focus mainly on Asia-Pacific region or North America? Choose one and explain why.”                                         | *Decision making*     | Model picked Asia-Pacific and wrote details.            |
| **Answer Engineering**  | “Use bullet points for statistics; include 3 actionable recommendations for companies.”                                     | *Answer engineering*  | Model added bullets and recommendations.                |
| **Semantic Filter**     | “Write in formal business tone, avoid hype language.”                                                                       | *Semantic filter*     | Output became more professional and precise.            |
| **Tail Generation**     | “Add a short conclusion summarizing opportunities for 2025–2030.”                                                           | *Tail generation*     | Added forward-looking conclusion.                       |


# Test Case 2: Creative Writing - Sci-Fi Short Story
## Scenario 2 – Sci-Fi Short Story

| Stage                   | Prompt Used                                                                                                             | Pattern Highlighted   | Output Effect                                   |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------------- | ----------------------------------------------- |
| **Basic Prompt**        | “Write a short sci-fi story about a robot exploring Mars.”                                                              | *Simple prompt*       | Produced ~150-word plain story.                 |
| **Query Decomposition** | “Describe separately: setting, main character, discovery event, twist ending.”                                          | *Query decomposition* | Model wrote each element separately.            |
| **Decision Making**     | “Should the twist be hopeful (discovery helps humans) or ominous (discovery threatens humans)? Choose one and justify.” | *Decision making*     | Model chose ominous twist and planned it.       |
| **Answer Engineering**  | “Expand into 500 words, suspenseful tone, cinematic descriptions.”                                                      | *Answer engineering*  | Longer, vivid story.                            |
| **Semantic Filter**     | “Avoid cliché phrases; maintain a tense, mysterious atmosphere.”                                                        | *Semantic filter*     | Style became darker and more original.          |
| **Tail Generation**     | “Add one more paragraph hinting at consequences for Earth.”                                                             | *Tail generation*     | Added alien code spreading to Earth at the end. |
## Conclusion

This experiment demonstrated that by applying structured prompting techniques—such as query decomposition, decision making, answer engineering, semantic filtering, and tail generation—we can guide an AI model to produce content that is more coherent, detailed, and fit for purpose. Starting from simple prompts, we progressively refined both a business report and a sci-fi short story, showing how each prompt adjustment improved structure, tone, accuracy, and creativity. The activity confirms that prompt patterns are a powerful tool for generating high-quality, customized content across both formal and creative domains.
